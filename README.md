## About This Project

This portfolio is my lab project for **Personal Website with HTML and CSS**. It introduces who I am, displays the projects I have built, and gives visitors a simple way to reach me.

## Sections

| Section | What it contains |
|---------|------------------|
| **Home** | Introduction, job title and profile photo |
| **Projects** | Project cards laid out with CSS Grid, each with a description, tech tags and GitHub link |
| **About** | Short bio, hobbies (Reading, Gaming, Swimming) |
| **Skills** | HTML, CSS, JavaScript, Git & GitHub, Responsive Design |
| **Contact** | Message form, email and social links |

## Featured Projects

- **Temperature Converter**: a JavaScript function that converts Celsius to Fahrenheit. [View code](https://github.com/joel-dev213/Temperature)
- **Fire Island Website**: a multi-section website project. [View code](https://github.com/joel-dev213)

## Key Features

- Fixed navigation bar with **smooth scrolling** to each section
- **CSS Grid** layout for the projects section
- Responsive design that adapts to different screen sizes
- High-contrast white text on a blue background for readability
- Styled contact form with clear input fields
- Consistent design across every section

## Built With

- **HTML5**: semantic structure (`header`, `nav`, `main`, `section`, `article`)
- **CSS3**: Grid, Flexbox, media queries, smooth scrolling
- **Git & GitHub**: version control and hosting
